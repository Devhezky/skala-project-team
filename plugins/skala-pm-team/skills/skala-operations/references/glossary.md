# Glossary — Indonesian ↔ English

Keep field terms in Indonesian in any reply language; contractors use them daily and translations sound wrong.

## Project

| Indonesian | English | Meaning |
|---|---|---|
| RAB (Rencana Anggaran Biaya) | Budget / cost estimate | Budget per work item |
| BOQ (Bill of Quantity) | Bill of quantities | Work volumes for tendering |
| RAP (Rencana Anggaran Pelaksanaan) | Execution budget | Internal budget once vendor prices are known |
| Bobot pekerjaan | Work weight | Item value ÷ total RAB |
| Kurva-S | S-curve | Cumulative plan vs actual |
| Progress fisik | Physical progress | Work installed on site, in % |
| Opname | Joint measurement | Measurement with the client, basis for payment |
| Deviasi | Deviation / variance | Actual minus plan |
| Jalur kritis | Critical path | Tasks that set the finish date |
| Baseline | Baseline | Locked reference plan |
| Variation order / pekerjaan tambah-kurang | Change order | Scope change outside the contract |
| Termin | Progress payment | Staged payment by progress |
| Retensi | Retention | Payment held until the maintenance period ends |
| BAST (Berita Acara Serah Terima) | Handover certificate | Formal handover record |
| Masa pemeliharaan | Defect liability period | Repair period after handover |

## Administration

| Indonesian | English | Meaning |
|---|---|---|
| Nota / struk | Receipt | Proof of purchase |
| Kasbon | Cash advance | Money advanced to a foreman or worker |
| Faktur / invoice | Invoice | Bill to the client |
| Pencatatan pengeluaran | Expense entry | Recording actual project cost |
| Cost control | Cost control | Budget vs actual |
| PPN | VAT | Value-added tax |
| Ongkir | Delivery cost | Material delivery charge |
| Lunas / belum bayar | Paid / unpaid | Payment status |
| Tempo | On credit | Pay later |

## People

| Indonesian | English | Meaning |
|---|---|---|
| Mandor | Site foreman | Daily site lead |
| Tukang | Skilled worker | Carpenter, mason, painter… |
| Helper / kenek | Labourer | Assists a tukang |
| PIC (penanggung jawab) | Person in charge | The one accountable for a task |
| Subkon | Subcontractor | Third party for specialist work |
| Estimator | Estimator | Prepares RAB and BOQ |
